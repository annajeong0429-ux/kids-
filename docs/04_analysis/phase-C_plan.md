## 1. 목표

안심존에서 **도착 당일 바로 실행되는** 분석 코드를 미리 완성한다. 폐쇄망에서 가장 큰 위험은 성능이 아니라 "현장에서 코드가 안 돌아 시간을 잃는 것"이다 (제안서 4.8).

완료 기준:
- 실데이터와 같은 폴더·JSON 구조의 **합성 데이터**로 `색인 → 마스크 생성 → 분할 → 학습 → 평가 → 시각화` 전체가 오류 없이 실행된다.
- 평가 스크립트가 PRD 지표 K-01~K-04를 D-18·D-19 기준(홀드아웃에서만)으로 계산한다.
- 반입 패키지 목록과 안심존 실행 순서(README)가 있다.

### 2-2. 설계 원칙

- **오프라인 전제:** 인터넷 다운로드 코드 없음. 사전학습 가중치는 로컬 파일 경로로만 읽고, 없으면 처음부터 학습하는 경로로 자동 전환한다.
- **의존성 최소화:** PyTorch·torchvision·NumPy·pandas·Pillow·OpenCV·scikit-learn·SciPy·matplotlib만 사용 (제안서 4.6 반입 목록 범위). `segmentation_models_pytorch` 같은 추가 라이브러리는 쓰지 않는다.
- **Python 호환:** 안심존 Python **3.13** (팀장 확인, ⚠️ 현장 재확인). 3.10 이상 문법으로 작성하고 3.13에서 검증한다.
- **실데이터·가중치 커밋 금지:** `.gitignore` 로 `data/`, `*.pt` 등 제외 (D-10). 결과 수치·그래프는 반출 심의 후에만 저장소에 넣는다.
- **사전학습 가중치:** 반입 가능(F-INFO-05) → ImageNet 사전학습 EfficientNet-B0 가중치 파일(torchvision 공식, 약 20MB)을 함께 반입하는 것을 기본 경로로 한다. 경량 U-Net은 예비 경로로만 유지.
- **재현성:** 시드, 분할 CSV, 설정 JSON, 패키지 버전을 실행마다 `runs/<날짜>/` 에 저장.

### 2-3. GPU 없음(CPU 전용) 대응 — F-INFO-05

GPU가 없으면 학습 속도가 크게 떨어진다. ⚠️ 아래 시간은 CPU 코어 수를 모르는 상태의 대략적 추정이며, 코드 완성 후 로컬 CPU에서 실측해 다시 적는다.

| 항목 | 대응 |
|---|---|
| 입력 해상도 | 분할·4징후 256×256 (제안서 예선 검증과 동일), 분류 224×224 |
| 사전학습 활용 | ImageNet 가중치로 시작 → 학습 epoch을 줄여도 수렴. 초반 몇 epoch은 인코더를 고정하고 헤드만 학습하는 옵션 |
| 학습 순서 (D-20 ①, H2 최우선) | ① 아토피 마스크 보유분으로 **분할 + 4징후** 먼저 (H1·H2·H3) → ② 질환군 분류(H-CLS)는 군별 균형 표본(예: 군당 최대 N장)으로 축소 학습 |
| **이어서 학습(resume)** | 매 epoch 체크포인트 저장, 다음 방문 때 이어서 학습. 방문 간 학습이 끊겨도 진행이 사라지지 않게 함 (방문 시간 제한 대비) |
| 시간 예산 | 학습 시작 전 `--benchmark` 로 배치당 시간을 재고, 남은 방문 시간에 맞춰 epoch 수를 자동 제안 |
| 전처리 캐시 | 첫 실행 때 리사이즈한 이미지·마스크를 캐시해 이후 epoch의 디스크·디코딩 시간을 줄임 |

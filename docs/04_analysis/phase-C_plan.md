## 1. 목표

안심존에서 **도착 당일 바로 실행되는** 분석 코드를 미리 완성한다. 폐쇄망에서 가장 큰 위험은 성능이 아니라 "현장에서 코드가 안 돌아 시간을 잃는 것"이다 (제안서 4.8).

완료 기준:
- 실데이터와 같은 폴더·JSON 구조의 **합성 데이터**로 `색인 → 마스크 생성 → 분할 → 학습 → 평가 → 시각화` 전체가 오류 없이 실행된다.
- 평가 스크립트가 PRD 지표 K-01~K-04를 D-18·D-19 기준(홀드아웃에서만)으로 계산한다.
- 반입 패키지 목록과 안심존 실행 순서(README)가 있다.

## 2. 설계

### 2-1. 폴더 구조 (`analysis/`)

| 경로 | 역할 | PRD 연결 |
|---|---|---|
| `config.py` | 경로·하이퍼파라미터·시드 (JSON 설정 파일로 덮어쓰기) | 재현성 |
| `data/index.py` | `D65/` 폴더를 훑어 JSON을 읽고 색인 CSV 생성 (진단명→4개 군, iga, 4징후, 카메라, 나이, 마스크 유무) | H0 |
| `data/masks.py` | `skin_area`·`lesion_area` 마스크로 3-클래스 정답(배경·피부·병변, 겹치면 병변 우선) 생성. 마스크 파일이 없으면 좌표(B-spline 제어점)로 대체 생성하고 경고 | H1·H2 |
| `data/split.py` | **학습 / 임계값 조정 / 홀드아웃 3분할** (진단·iga 층화, 시드 고정, 분할 CSV 저장). identifier로 같은 환자를 묶을 수 있으면 환자 단위 분할 | D-19 |
| `data/dataset.py` | PyTorch Dataset — 라벨이 없는 항목(4징후·마스크)은 손실에서 제외하는 마스킹 | — |
| `models/multitask.py` | **EfficientNet-B0 공유 인코더 + 3갈래 헤드**: 분할(FPN 경량 디코더, 3-클래스) / 4징후(각 0~3) / 질환군 분류(4개 군, 정상 처리는 C-Q 확인) | H1·H3·H-CLS, D-20 ① |
| `models/unet_small.py` | 사전학습 가중치 반입 불가 시 대체 — 처음부터 학습하는 경량 U-Net (예선 검증 구조) | H1 대체 경로 |
| `train.py` | 다중 과제 학습 (분할 CE+Dice, 4징후·분류 CE, 클래스 가중치), 체크포인트·학습 로그 CSV, GPU 있으면 자동 사용 | — |
| `evaluate.py` | 홀드아웃 평가: K-01 DSC·IoU(이미지 평균·전체 합산 둘 다), K-02 면적 비율 vs iga(Spearman ρ, Jonckheere-Terpstra, 등급별 중앙값 — **정답 마스크·예측 마스크 둘 다**), K-03 4징후 Spearman ρ·가중 kappa, K-04 정확도·군별 재현율·혼동행렬, 연령대별 분석 | K-01~K-04, D-18, D-20 ① |
| `visualize.py` | 분할 오버레이, iga 등급별 면적 분포, 혼동행렬, 학습 곡선, Grad-CAM(D-20 ②) | 결과보고서 |
| `tools/make_synthetic.py` | 실데이터와 같은 구조의 가짜 데이터 생성기 (랜덤 이미지·마스크·JSON) — 로컬·CI 검증용 | 검증 |
| `tests/` | 합성 데이터로 전체 파이프라인 스모크 테스트 + 지표 함수 단위 테스트(알려진 값으로 검산) | 검증 |
| `requirements-safezone.txt` | 반입 패키지 목록 (버전 고정) | 반입 |
| `README.md` | 안심존 실행 순서, 반출 대상 산출물 목록 | 반입·반출 |

### 2-2. 설계 원칙

- **오프라인 전제:** 인터넷 다운로드 코드 없음. 사전학습 가중치는 로컬 파일 경로로만 읽고, 없으면 처음부터 학습하는 경로로 자동 전환한다.
- **의존성 최소화:** PyTorch·torchvision·NumPy·pandas·Pillow·OpenCV·scikit-learn·SciPy·matplotlib만 사용 (제안서 4.6 반입 목록 범위). `segmentation_models_pytorch` 같은 추가 라이브러리는 쓰지 않는다.
- **Python 호환:** 안심존 Ubuntu 20.04 기본 Python 3.8을 가정하고 3.8 문법으로 작성 (C-Q4로 확인).
- **실데이터·가중치 커밋 금지:** `.gitignore` 로 `data/`, `*.pt` 등 제외 (D-10). 결과 수치·그래프는 반출 심의 후에만 저장소에 넣는다.
- **재현성:** 시드, 분할 CSV, 설정 JSON, 패키지 버전을 실행마다 `runs/<날짜>/` 에 저장.

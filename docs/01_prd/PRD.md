## 1. 배경

### 1-1. 소아 아토피피부염은 규모가 크고, 소아에 집중되어 있다 🔒

출처: 국민건강보험공단, 「2018~2022년 아토피피부염 환자 건강보험 진료 현황」 (2023.8.14) — D-03

| 지표 | 수치 |
|---|---|
| 2022년 아토피피부염 진료인원 | 97만 1,116명 |
| 그중 9세 이하 | 27만 1,613명 (28.0%, 전 연령대 중 최다) |
| 인구 10만 명당 진료인원 | 전체 1,889명 vs 9세 이하 7,680명 (4배 이상) |
| 총 진료비 | 2018년 823억 원 → 2022년 1,765억 원 (+114.4%) |
| 연령대별 진료비 비중 | 9세 이하: 환자 28.0% · 진료비 11.1% / 20대: 환자 16.7% · 진료비 34.1% |

- 만성 질환이라 진단 후 장기 경과 관찰과 반복 내원이 따른다.
- 9세 이하와 20대의 진료비 구성 차이는 "소아기에 관리가 덜 된 환자가 성인기에 고비용 치료로 이어진다"는 구조를 **시사**할 뿐, 인과는 검증되지 않았다 ⚠️ (제안서 7.2도 같은 단서를 붙임).

### 1-2. 소아 의료 접근성은 줄고 있다 🔒

| 지표 | 수치 | 출처 (제안서 표 2) |
|---|---|---|
| 소아청소년과 폐업 | 2017~2022.8 662곳, 연평균 132곳 | 보건복지부·국정감사 자료 (의협신문, 2022) |
| 개업 대비 폐업 | 2025년 신규 59곳 vs 폐업 89곳 — 진료과목 중 유일하게 폐업 > 개업 | 심평원 개폐업 현황 (약사공론, 2026) |

→ 재진까지의 기간을 보호자가 혼자 판단해야 하는 상황이 늘고, 짧은 진료 시간 안에 경과를 정확히 전달할 수단이 필요하다.

### 1-3. 기존 서비스는 기록을 정량화하지 않는다 🔒

| 한계 | 내용 |
|---|---|
| 단일 시점 판단 | 대부분의 피부 AI 서비스는 사진 한 장을 분류하는 데 그친다. 만성 질환 보호자에게 필요한 것은 "어떻게 변하고 있는가"다. |
| 기록하지만 정량화하지 않음 | EczemaWise·아토맘·아토닥은 사진·증상을 저장하지만 병변 면적이나 EASI 구성 요소를 자동 산출하지 않는다 (제안서 표 14, 2026.8 기준). |
| 지역·시기 맥락 부재 | 계절·지역별 감염성 피부질환 유행 정보를 반영하지 않는다. |

### 1-4. 데이터가 이것을 가능하게 한다 🔒

- 대회 데이터셋: 소아청소년 피부질환 이미지 데이터 (건양대학교의료원, AI-Hub 원본) — 10개 병원, 40종, 58,186장.
- 아토피피부염 10,166장에 **EASI 구성 4징후**(홍반·구진·찰상(긁은 자국)·태선화, 각 0~3점)와 **피부/병변 분할 마스크**, **iga_grade**(0~4)가 함께 있다.
- 공식 베이스라인 (EfficientNet-B0 인코더): 피부-배경 분할 DSC 0.9947, 아토피 병변 분할 DSC 0.8025, 40종 분류 Top-1 80.12% / Top-3 94.1%.
- 예선에서 공개 데이터(HAM10000 800장)로 학습→추론→마스크→면적 비율→시각화 파이프라인이 동작함을 확인했다 (병변 DSC 0.8847 — **성능 주장이 아닌 코드 동작 확인용**, 제안서 4.8).

### 1-5. 제약 조건 🔒

| 제약 | 내용 | 근거 |
|---|---|---|
| 데이터 반출 | 원본 데이터셋 반출 불가. 분석 결과물은 반출 심의 후 가능 (1~2주) | F-INFO-01 |
| 분석 환경 | 안심존 폐쇄망 (Ubuntu 20.04, Python·R), 인터넷·자동 설치 불가, 패키지 사전 반입, 전자기기 반입 금지 | 제안서 4.6 |
| 종단 데이터 없음 | 같은 환자의 시점 간 연결이 설계상 차단 → 시계열 판정 임계값은 대회 데이터로 검증 불가 | 제안서 4.4 |
| 세그멘테이션 범위 | 마스크는 아토피 중심 (건선·정상 일부). 감염성 질환군에는 없음 | 제안서 2.2 |
| 도메인 갭 | 학습 사진은 병원 DSLR·더모스코피, 실사용은 가정 스마트폰 | 제안서 8.3 |
| 규제 | 식약처 웰니스 판단기준(2026.2 개정)상 "피부 질환의 유·무 및 정도 표시"는 의료기기 예시 → 정량 표시·추세 판정·질환 분류는 의료기기 판단 가능성 높음 | 패키지 05 |

## 2. 문제 정의

| ID | 누가 | 어떤 상황에서 | 무엇 때문에 어려운가 | 근거 수준 |
|---|---|---|---|---|
| P-01 | 아토피 진단을 받은 0~9세 아동의 보호자 | 국소 치료제 처방 후 재진까지 1~2주 | "나아지고 있는가"를 판단할 객관적 기준이 없다. 사진을 찍어도 조명·각도가 달라 비교가 안 되고, 눈대중과 검색에 의존한다. | 통계 🔒 / 보호자 행동은 ⚠️ (인터뷰 미실시 — 패키지 02 리서치 계획) |
| P-02 | 같은 보호자 | 병변이 번지거나 진물·발열이 생김 | 지금 병원에 가야 하는지 판단하기 어렵다. 과소 내원(악화 후 방문)과 과다 내원이 모두 생긴다. | ⚠️ |
| P-03 | 소아청소년과·피부과 의료진 | 재진 1인당 3~5분 | 지난 기간의 경과를 보호자 진술("좀 나아진 것 같아요")에만 의존한다. | ⚠️ (패키지 페르소나 가설, 의료진 인터뷰 미실시) |
| P-04 | 보호자 | 물집·농포 등 감염성 질환이 의심됨 | 이미지만으로는 판단이 어렵고, 지금 이 지역에 무엇이 유행하는지 알 수 없다. | ⚠️ (D-06으로 범위 포함) |
| P-05 | 팀 (기술 문제) | 병원 사진으로 학습한 모델을 가정 사진에 적용 | 도메인 갭, 종단 데이터 부재로 실사용 정확도와 추세 판정 임계값을 대회 기간에 증명할 수 없다. | 🔒 (제안서 4.4·8.3) |

**핵심 문제 한 줄:** 보호자는 이미 사진을 찍고 있지만, 그 관찰을 판단으로 연결할 **척도**가 없다 (제안서 3.1).

## 4. 핵심 기능

### 4-1. 대회 분석 과제 (구간 1)

대회 산출물은 제품 기능이 아니므로 `F-xx` 대신 제안서의 가설 ID를 그대로 쓴다.

| ID | 과제 | 방법 (제안서) | 산출물 |
|---|---|---|---|
| H1 | 병변 분할 | EfficientNet-B0 인코더 + U-Net/FPN, 3-클래스(배경·피부·병변). 사전학습 가중치 반입 불가 시 경량 U-Net (4.3.1) | 클래스별 DSC·IoU |
| H2 | 면적 비율 ↔ 임상 중증도 | 면적 비율 = 병변 ÷ (피부 + 병변) 픽셀, iga_grade 0~4 등급별 분포 비교 | 등급별 분포 그래프, 단조성 검정 결과 |
| H3 | 4징후 추정 | 회귀 헤드(각 0~3), 예측-실제 상관 | 항목별 상관·일치도 |
| H-CLS | 질환군 분류 | 4개 군(염증성 7·선천성 11·감염성 7·기타 15) → 세부 후보 (4.3.2). D-06의 전제 | 군별 정확도·혼동행렬 |
| H4 | 스마트폰 일반화 | 스마트폰 검증셋 DSC 하락폭 | ❓ PQ-07 — 안심존 데이터에는 스마트폰 아토피 사진이 없음 (제안서 8.3) → 대회 범위 밖으로 둘지 확인 |

### 4-2. 웹앱 기능 (구간 2)

패키지 03장의 F-01~F-17을 출발점으로 하고 결정 사항을 반영했다. 변경 내역은 4-3.

| F-03 | 아동 프로필 | 별칭, 출생 연도, 성별. 실명·출생 월일 수집 안 함. 만 10세 이상은 대상 외 안내 | Must |
| F-04 | 진단·처방 입력 | 진단(아토피피부염), 진단일, 처방 약(자유 입력), 재진일. 첫 촬영이 baseline | Must |
| F-05 | 촬영 부위 등록 | 신체 도식에서 선택, 아동당 최대 3부위, 얼굴·생식기 선택 불가 | Must |
| F-06 | 가이드 촬영 | **웹 브라우저 카메라**로 프레임 오버레이, 거리·조명 안내, 이전 사진 반투명 겹침 | Must |
| F-07 | 촬영 품질 검사 | 흐림·노출 규칙 검사 + 얼굴 감지 시 폐기, **업로드 전 브라우저에서** 수행, 실패 사유 1개 + 해결 방법 | Must |
| F-08 | 전후 비교 뷰 | 같은 부위 두 날짜를 슬라이더·나란히 보기로 비교 | Must |
| F-09 | 증상·복약 일지 | 가려움·수면 방해(0~10), 복약 체크, 메모 | Must |
| F-10 | 진료용 리포트 | 기간 선택 → 사진 타임라인, 일지 요약, 복약 순응도, 진료 화면 모드, PDF. 아동 별칭만 표시. 자동 해석 문장 없음 | Must |

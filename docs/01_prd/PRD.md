## 1. 배경

### 1-1. 소아 아토피피부염은 규모가 크고, 소아에 집중되어 있다 🔒

출처: 국민건강보험공단, 「2018~2022년 아토피피부염 환자 건강보험 진료 현황」 (2023.8.14) — D-03

| 지표 | 수치 |
|---|---|
| 2022년 아토피피부염 진료인원 | 97만 1,116명 |
| 그중 9세 이하 | 27만 1,613명 (28.0%, 전 연령대 중 최다) |
| 인구 10만 명당 진료인원 | 전체 1,889명 vs 9세 이하 7,680명 (4배 이상) |
| 총 진료비 | 2018년 823억 원 → 2022년 1,765억 원 (+114.4%) |
| 연령대별 진료비 비중 | 9세 이하: 환자 28.0% · 진료비 11.1% / 20대: 환자 16.7% · 진료비 34.1% |

- 만성 질환이라 진단 후 장기 경과 관찰과 반복 내원이 따른다.
- 9세 이하와 20대의 진료비 구성 차이는 "소아기에 관리가 덜 된 환자가 성인기에 고비용 치료로 이어진다"는 구조를 **시사**할 뿐, 인과는 검증되지 않았다 ⚠️ (제안서 7.2도 같은 단서를 붙임).

### 1-2. 소아 의료 접근성은 줄고 있다 🔒

| 지표 | 수치 | 출처 (제안서 표 2) |
|---|---|---|
| 소아청소년과 폐업 | 2017~2022.8 662곳, 연평균 132곳 | 보건복지부·국회 국정감사 자료 (의협신문, 2022) |
| 개업 대비 폐업 | 2025년 신규 59곳 vs 폐업 89곳 — 진료과목 중 유일하게 폐업 > 개업 | 건강보험심사평가원 개폐업 현황 (약사공론, 2026) |

⚠️ 추론: 재진까지의 기간을 보호자가 혼자 판단해야 하는 상황이 늘고, 짧은 진료 시간 안에 경과를 정확히 전달할 수단이 필요하다.

### 1-3. 기존 서비스는 기록을 임상 지표로 정량화하지 않는다 🔒

출처: 제안서 5.3 표 14 (2026.8 기준 공식 소개자료·앱 스토어 설명)

| 서비스 | AI 이미지 분석·분류 | 병변 면적 정량 측정 | EASI 구성 요소 이미지 자동 산출 | 질병관리청 역학 연동 |
|---|---|---|---|---|
| EczemaWise (미국) | X | X | X | X |
| 아토맘 | O | X | X | X |
| 아토닥 | O | △ | X | X |

- 단일 시점 판단: 대부분의 피부 AI 서비스는 사진 한 장을 분류하는 데 그친다. 만성 질환 보호자에게 필요한 것은 "어떻게 변하고 있는가"다.
- 지역·시기 맥락 부재: 계절·지역별 감염성 피부질환 유행 정보를 반영하지 않는다.
- 단, 세 서비스는 이미 출시·실사용자가 있고 키즈덤 AI는 미검증이다 (표 14 마지막 두 행).

## 4. 핵심 기능

### 4-1. 대회 분석 과제 (구간 1)

#### 4-1-1. 가설 검증 과제

대회 산출물은 제품 기능이 아니므로 `F-xx` 대신 제안서의 가설 ID를 그대로 쓴다.

| ID | 과제 | 방법 (제안서) | 산출물 |
|---|---|---|---|
| H0 | 데이터 구조 확인 | 안심존 첫 방문 시 PQ-10 항목 확인 | 확인 결과표 (decisions.md) |
| H1 | 병변 분할 | EfficientNet-B0 인코더 + U-Net/FPN, 3-클래스(배경·피부·병변). 사전학습 가중치 반입 불가 시 경량 U-Net (4.3.1) | 클래스별 DSC·IoU |
| H2 | 면적 비율 ↔ 임상 중증도 | 면적 비율 = 병변 ÷ (피부 + 병변) 픽셀, 중증도 등급별 분포 비교 | 등급별 분포 그래프, 단조성 검정 결과 |
| H3 | 4징후 추정 | 회귀 헤드(각 0~3), 예측-실제 상관 | 항목별 상관·일치도 |
| H-CLS | 질환군 분류 | 4개 군(염증성 7·선천성 11·감염성 7·기타 15) → 세부 후보 (4.3.2). D-06의 전제. 정상 피부 처리는 ❓ PQ-10 | 군별 정확도·재현율·혼동행렬 |
| H4 | 스마트폰 일반화 | 스마트폰 검증셋 DSC 하락폭 | ❓ PQ-07 — 안심존 데이터에는 스마트폰 아토피 사진이 없음 (제안서 8.3) |

## 5. 성공 지표

### 5-1. 대회 지표

공통 재현성 조건: 분할 비율·시드·데이터 버전·패키지 버전을 기록한다 (CLAUDE.md 3-1).

**데이터 3분할 (D-19):** ① 학습용 ② 임계값 조정용(F-13 신뢰도 하한, F-18 판단 불가·감염성 하한, 조기 종료 등) ③ **최종 평가용 홀드아웃**. K-01~K-04와 공개 기준 충족 여부는 **홀드아웃에서만** 측정하고, 홀드아웃은 학습·임계값 조정·모델 선택에 쓰지 않는다. 같은 데이터로 임계값을 고르고 평가하면 성능이 낙관적으로 나오기 때문이다.

| ID | 지표 | 목표 | 측정 방법 | 근거 |
|---|---|---|---|---|
| K-01 (H1) | 아토피 병변 분할 DSC | **0.75 이상** (공식 0.8025의 약 90%) | 검증셋에서 병변 클래스 DSC·IoU. 산출 방식(이미지별 평균 vs 전체 픽셀 합산)은 공식 베이스라인과 같은 방식으로 맞추되, 공식 방식을 확인할 수 없으면 둘 다 보고 | 제안서 표 10 |
| K-02 (H2) | 면적 비율의 중증도 단조성 | 등급이 높을수록 면적 비율이 증가 — **순위 상관 ρ ≥ 0.3 + 추세 검정 p < 0.05 + 등급별 중앙값이 모두 증가** (D-18) | 등급별 분포 + Spearman ρ + 추세 검정(예: Jonckheere-Terpstra). **정답 마스크 기준과 예측 마스크 기준을 둘 다 보고** (지표 자체의 타당성 / 모델 포함 타당성) | 제안서 표 10 (판정 기준은 원천에 없음) |
| K-03 (H3) | 4징후 예측-실제 대응 | 4개 항목 모두 **Spearman ρ ≥ 0.3**, 홍반은 **ρ ≥ 0.5** (D-18) | 항목별 Spearman ρ, 가중 kappa. 미달 항목은 축소 | 제안서 표 10 |
| K-04 (H-CLS) | 4개 질환군 분류 성능 | ❓ PQ-06 (원천 문서에 목표값 없음) — **감염성 군 재현율 하한은 F-18·F-19 공개 조건으로 사용** | 검증셋 정확도, 군별 재현율(특히 감염성), 혼동행렬 | 제안서 4.3.2 |

### 5-3. 안전 지표 — 측정 공백 ❓

- 가장 큰 위험은 **실제로는 악화인데 호전·유지로 보여 진료가 늦어지는 것**(패키지 R-01)과, 감염성 병변을 다른 군으로 분류해 상담 안내가 나가지 않는 것이다.
- 악화 탐지 민감도는 종단 파일럿(처방 후 2~4주 추적 + 의사 판단 비교, IRB 필요)으로만 측정할 수 있다 (패키지 11).
- D-11(전체 공개)과 F-14(추세 판정)를 함께 하면, **안전 지표를 측정하지 않은 채 판정 기능을 공개**하게 된다 → ❓ PQ-03에서 공개 조건을 정해야 한다.
- 출시 전 테스트 항목: F-11(위험 증상 체크 시 AI 결과와 무관하게 안내 표시), 비진단 고지 표시, F-18 판단 불가 시 상담 안내 — Phase 5 테스트 계획에 포함.
